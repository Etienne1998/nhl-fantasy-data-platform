# NHL Fantasy Data Platform

## Project Overview

An end-to-end data engineering and machine
learning project using NHL statistics.

The objective is to build an automated data
platform to ingest, transform, store and analyze
NHL data to generate fantasy hockey projections.

## Technologies

- Microsoft Azure
- Azure Data Lake Storage Gen2
- Azure Data Factory
- Azure Databricks
- Python
- PySpark
- Delta Lake
- SQL
- Machine Learning
- GitHub
